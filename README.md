# 🌍 TravelMate – Travel Destination Recommendation System

<p align="center">
  <strong>Explore the World, Plan Your Journey!</strong>
</p>

TravelMate is a travel destination recommendation and trip-planning web application designed to help users explore destinations, discover travel options, and organize their trips in one place.

## ✨ Key Features

- 🌍 **Destination Discovery** – Explore different travel destinations.
- 🧭 **Travel Recommendations** – Discover destinations through the recommendation system.
- 🗺️ **Interactive Maps** – View destination locations.
- 🏨 **Stay Management** – Explore accommodation options.
- 🚗 **Transport & Rentals** – Browse transportation and rental options.
- 💰 **Budget Planner** – Plan trips according to your budget.
- 📅 **Trip Planning** – Organize your travel plans.
- 🔐 **Authentication** – User authentication functionality.
- ⚙️ **Admin Dashboard** – Manage travel catalog information.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/manishcodes-tech/travel-destination-recommendation-system.git
```

### 2. Open the project

```bash
cd travel-destination-recommendation-system
```

### 3. Install frontend dependencies

```bash
npm install
```

### 4. Start the frontend

```bash
npm run dev
```

### 5. Install backend dependencies

Open another terminal:

```bash
cd backend
pip install -r requirements.txt
```

### 6. Configure environment variables

Create a `.env` file inside the backend folder using `.env.example` as a reference.

Add your own API keys and database configuration where required. Never upload real credentials to GitHub.

### 7. Start the backend

From the backend directory, run:

```bash
uvicorn main:app --reload
```
